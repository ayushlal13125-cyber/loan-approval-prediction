# 💰 Loan Approval Prediction System

A Machine Learning based web application that predicts whether a loan application will be approved or rejected based on applicant details.

Built using Python, Scikit-learn, and Streamlit.

# 📊 Machine Learning Model

The project uses:

## Logistic Regression

for predicting loan approval status based on:

- Gender
- Marital Status
- Education
- Self Employment
- Applicant Income
- Coapplicant Income
- Loan Amount
- Loan Amount Term
- Credit History
- Property Area
